# Kubernetes Platform Scenarios Repository

This repository contains **12 end-to-end Kubernetes scenario blueprints** (from intermediate to expert), each in its own folder with:

- `README.md` with architecture and step-by-step implementation guidance
- manifests, scripts, or pipeline definitions to bootstrap implementation
- practical commands to validate outcomes

## Structure

- `task-1/` Microservices migration to Kubernetes
- `task-2/` Black Friday resiliency
- `task-3/` GitOps & observability overhaul
- `task-4/` Multi-tenant SaaS platform
- `task-5/` Legacy monolith breakup
- `task-6/` Edge/IoT gateway
- `task-7/` Compliance & security hardening
- `task-8/` Multi-cluster federation
- `task-9/` Serverless on Kubernetes
- `task-10/` Chaos engineering
- `task-11/` CI/CD pipeline integration
- `task-12/` Cost optimization audit

> Note: manifests are production-oriented templates and may require cloud/provider-specific values before apply.
